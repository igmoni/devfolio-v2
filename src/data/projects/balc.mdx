# BALC — Computer Training Institute Website

## Overview

Built a responsive website for BALC, a computer training institute, to showcase courses, improve its online presence, and help students explore learning opportunities.

## Key Features

- Course and training information
- Responsive, mobile-friendly layouts
- Direct contact and inquiry options
- Scalable content structure for courses and blogs

## Objectives

- Strengthen the institute’s digital presence in Bangalore
- Help students understand available courses and skills
- Build trust through a professional online experience

## Tech Stack

- Next.js
- Tailwind CSS
- shadcn/ui
- MDX

## Development

- Rebuilt the website in 1–1.5 months
- Improved UI structure and responsiveness
- Used MDX for maintainable, scalable content
- Delivered and deployed the website for real-world use

## Impact

- Improved online visibility and accessibility
- Made course information easier to discover
- Enabled students to contact the institute directly
