# Reance — Full-Stack Freelance Marketplace

## Overview

Reance is a full-stack freelance marketplace designed to connect clients with independent professionals. It enables users to post projects, submit proposals, manage contracts, track milestones, and communicate in real time through a centralized platform.

## Key Features

- **Authentication:** Email/password login, Google OAuth, GitHub OAuth, and role-based access control.
- **Project Marketplace:** Create projects, browse opportunities, filter listings, and save projects or freelancer profiles.
- **Proposal Management:** Submit bids, review proposals, and manage hiring workflows.
- **Contract Management:** Create contracts, track milestones, submit deliverables, and monitor project progress.
- **Real-Time Messaging:** Enable live conversations between clients and freelancers using Socket.io.
- **Notifications:** Provide updates on proposals, contracts, messages, and other platform activities.
- **User Dashboards:** Dedicated dashboards for clients, freelancers, and administrators.
- **Reviews and Profiles:** Manage professional profiles, project history, ratings, and feedback.
- **File Management:** Support file uploads and media storage through Cloudinary and Multer.

## Tech Stack

**Frontend:** Next.js 16, React 19, TypeScript, Tailwind CSS 4, shadcn/ui, Radix UI, React Hook Form, Zod, Motion

**Backend:** Node.js, Express 5, TypeScript, PostgreSQL, Prisma ORM

**Authentication:** JWT, Passport.js, Google OAuth, GitHub OAuth

**Real-Time Communication:** Socket.io

**Storage and Email:** Cloudinary, Multer, Nodemailer, Resend

## Development Highlights

- Designed a modular REST API architecture with separate routes, controllers, services, and validation.
- Modeled relational data for users, projects, proposals, contracts, milestones, reviews, messages, and notifications.
- Implemented protected routes and role-based authorization for different user types.
- Built reusable UI components and responsive dashboards for multiple user roles.
- Developed real-time messaging and notification workflows using Socket.io.
- Organized the codebase for maintainability, scalability, and future feature expansion.
