## Craft — Set Up Projects Without Repeating the Same Work

## Overview

Craft is a TypeScript-based CLI tool that automates repetitive project setup. It helps developers scaffold applications and configure development tools through a single interactive workflow, reducing boilerplate and speeding up development.

Published on npm as `@igmoni/craft`, it supports project generation with Next.js, Vite, and Express.

## Key Features

- **Project Scaffolding:** Generate Next.js, Vite, and Express projects.
- **Language Selection:** Choose TypeScript or JavaScript where supported.
- **Database Configuration:** Set up PostgreSQL, MongoDB, or no database.
- **Authentication:** Configure supported authentication providers.
- **Development Tools:** Set up ESLint, Prettier, Husky, and Commitlint.
- **Tailwind CSS:** Include Tailwind CSS in supported configurations.
- **Environment Setup:** Generate `.env` files from `.env.example` when available.
- **Conflict Protection:** Detect existing files and avoid blindly overwriting them.

## Installation & Usage

```bash
npm install -g @igmoni/craft

craft init my-app

craft init my-app --framework vite --database none --js --tools eslint,prettier
```
