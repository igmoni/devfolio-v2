# JARVIS — Voice-Controlled Personal Assistant

## Overview

JARVIS is a Python-based voice assistant built as a college project to automate common computer tasks through voice commands. It combines speech recognition, text-to-speech, and system automation.

## Key Features

- Voice command recognition and processing
- Launch applications and open websites
- Provide date and time information
- Retrieve weather information
- Respond through text-to-speech
- Support extensible commands for additional functionality

## Tech Stack

- **Python**
- SpeechRecognition
- pyttsx3
- Webbrowser
- OS and system libraries

## How It Works

1. Captures voice input.
2. Converts speech into text.
3. Identifies the requested command.
4. Executes the corresponding action.
5. Responds through synthesized speech.

## Development Highlights

- Integrated multiple Python libraries into one application.
- Implemented voice-based system and web automation.
- Handled command processing and speech recognition errors.
- Structured commands to support future enhancements.
