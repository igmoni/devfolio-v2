# Samye Tibetan Medical Treatment Centre

## Overview

Developed a responsive healthcare website for Samye Tibetan Medical Treatment Centre, presenting traditional Tibetan medicine (Sowa Rigpa) through a modern, accessible digital experience.

## Key Features

- Appointment booking with date selection and available time slots
- Information about medical centres, treatments, and practitioners
- Patient testimonials and healthcare service details
- Contact information and centre locations
- Responsive layouts for mobile, tablet, and desktop
- SEO-friendly pages and metadata

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS

## Development Highlights

- Built the website from design to deployment for a real client.
- Created a Tibetan-inspired visual identity with a clean, trustworthy interface.
- Developed reusable components and an appointment scheduling workflow.
- Organized healthcare information for easy navigation and accessibility.
- Optimized responsiveness, performance, and maintainability.

## Key Learnings

- Translating client requirements into practical features
- Designing user-friendly healthcare experiences
- Building appointment workflows and responsive interfaces
- Delivering and deploying a real-world client project
